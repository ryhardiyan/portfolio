Backend: Node.js, Express.js
Hosting & Deployment: (misal: Vercel, Netlify, Azure, DigitalOcean)
Database: (misal: MongoDB, PostgreSQL)
Lainnya: Git, GitHub (CI/CD), Figma, dan alat lainnya
---

🚀 Cara Jalankan di Lokal
1. Clone repository:
git clone https://github.com/ryhardiyan/portfolio.git
cd portfolio
2. Install dependencies:
npm install
3. Jalankan server:
npm start
4. Akses di browser:
http://localhost:3000
